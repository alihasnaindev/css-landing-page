# CSS Landing Page

This is a simple landing page I built while learning CSS.

After practicing basic CSS with smaller projects, I wanted to use those concepts to create a complete webpage. This project helped me practice styling different sections and working with the overall layout of a page.

## What I Used

- HTML5
- CSS3

## What I Practiced

While building this project, I practiced:

- Colors and backgrounds
- Fonts and text styling
- Margins and padding
- Width and height
- Borders and border-radius
- Positioning
- Buttons and hover effects
- Basic page layout

## About the Project

This project is part of my frontend development learning journey. My main focus was to understand how CSS can be used to style and organize a webpage.

It is still a simple project, but each project is helping me understand CSS better and become more comfortable with writing it myself.

## Future Improvements

As I learn more CSS, I would like to improve this project by:

- Making it responsive
- Improving the layout
- Adding more sections
- Improving the mobile design
- Adding more interactive elements
